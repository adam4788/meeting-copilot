# From live answers to reviewed notes

The **Review notes** workspace is a deliberate handoff step, not automatic
minutes or an authoritative decision record.

1. Ask a question, or use **Catch me up** / **Extract actions**. These use bounded
   recent context, not a promise of full-meeting coverage.
2. Choose **Keep as note** on a useful answer. Pinning makes no model call.
3. Edit the note to separate decisions, proposals, questions, and commitments.
   Confirm owners and deadlines against evidence. Leave missing details
   unspecified instead of guessing.
4. Expand **Source evidence at pin time** to inspect available retrieved evidence;
   use the answer's frozen transcript context separately when needed. Neither is
   independent factual verification.
5. Mark the note reviewed. Any edit resets review. Remove irrelevant notes.
6. **Copy reviewed notes** becomes available once every note is reviewed and
   nonempty. Confirm the clipboard disclosure, then choose where to save it.

No export is sent to teammates automatically. Clipboard history and sync may
retain exported notes. The workspace is limited to 12 notes; each note is capped
at 12,000 characters and discloses truncation. Source evidence is bounded too.
Notes are ephemeral: Clear/New meeting, session changes, pane closure or reload
remove them. This does not remove exported copies.

This is a small review-first workflow inspired by persistent meeting workspaces,
without silently introducing transcript storage, auto-joining, or recording.
